# 银龄善治 · 养老资源配置情景助手

基于上海市公开人口统计、保基本床位名单与政策参照，对不同约束下的新增床位配置做情景比较与独立校验。数据为项目留存快照，仅用于情景讨论，不代表实时空床、实际照护需求或政策达标结论。

## 访问

打开本 Space 页面即可使用。首次唤醒可能需要等待数十秒（免费层闲置后休眠）。

## 配置

本 Space 通过环境变量 `DEEPSEEK_API_KEY` 注入密钥，不在仓库中保存任何密钥。
